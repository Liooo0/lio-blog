## 为什么做这个

家里出租房子，每个月要开收据。传统方式是针式打印机加复写纸，一式两联，底联留着、租客拿走一联。数据全靠手写和本子记，查历史、算月度汇总都很痛苦。我需要一个工具：录入快、能打印、能统计、能导出。

## 功能

- **房间管理** — 每个房间预设房租、水单价、电单价
- **新建收据** — 选房间自动带出单价 → 填本次水/电表读数 → 自动算金额 → 保存；支持"从上次读数复制"和批量录入
- **A4 PDF 打印** — reportlab 生成简洁 A4 版式，含中文大写金额，可预览可送打印
- **针式打印模式** — 传统针式打印机只认纯文本点阵，所以这个模式生成等宽字体纯文本收据（约 40-80 字符宽），走系统 `lp` 命令送打印机，也可存成 .txt 拷到 Windows 打；配复写纸一次打两联
- **月度汇总** — 按年份选月份，房租/水电合计表格 + 柱状图
- **数据导出** — CSV / Excel；数据库一键备份，退出时自动备份
