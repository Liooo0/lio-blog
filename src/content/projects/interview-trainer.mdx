## 为什么做这个

面试准备最有效的方式不是"看"，是"练"。但对着镜子练没人给你反馈，找真人模拟又难约。我手上攒了三份面试备战材料（75 个真实岗位的必问题 + 应答思路 + 项目话术），需要一个能把我"练"起来的工具：出题 → 我答 → 它点评 → 记录复盘。

## 功能

- **31 道高频题**：全部提炼自真实岗位备战材料，按方向筛选——RAG / Agent / Prompt / 模型评测 / 产品 / 通用
- **一轮模拟 5 题**：随机抽题逐题作答，轮末平均分总结
- **AI 点评**：评分 1-10 + 一句话总评 + 优点 + 不足 + 参考回答要点，点评会**强制结合我的真实项目**（job-hunter 5100+ 投递、95分逆向监控、摄影天气、LLM 竞技场、房租专家）给嫁接建议
- **项目话术注入**：启动时实时读取我的项目话术文档，把对应方向的示范话术带进点评
- **历史回看**：每次答题和点评都存 SQLite，列表 + 单条回看，随时复盘

## 技术要点

- Flask + 原生 HTML/JS，零构建工具，`python3 app.py` 一条命令跑
- LLM 调用有完整防护：限速（每分钟 ≤8 次）、30s 超时、失败重试 + 前端手动重试
- 凭据只读系统配置，不落代码

## 实际效果

- 端到端实测：强回答得 6 分、弱回答得 3 分，评分有区分度不虚高
- 4 个独立审查视角共发现 17 个问题（限速绕过、JSON 解析、前端竞态等）全部修复
- 面试前打开它练 20 分钟，比翻文档管用
