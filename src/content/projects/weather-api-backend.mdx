## 为什么做这个

我喜欢摄影，拍日出日落蓝调时刻本质上是"看天吃饭"：云量、能见度、风力、太阳方位，缺一不可。以前每天要自己翻好几个天气 App，再凭经验猜今晚值不值得出门、去哪拍。这套判断完全可以自动化。

## 它做什么

- **每天定时推送** — 16:00 通过 wxpusher 推一条微信消息：本地化的日出/日落/蓝调时刻摄影条件分析
- **异地自适应** — 每个订阅者按自己上报的坐标独立拉天气，不再写死一个城市；位置通过 H5 定位页一键上报（高德 JS API 精确定位 → IP 兜底 → 手动输入）
- **机位推荐** — 以你为圆心找 5km 内的机位：日落分高推朝西机位、日出分高推朝东机位；5km 内没有就自动放宽到最近的 3 个

## 纯规则打分，全链路可解释

刻意没有用 LLM——气象判断是规则问题，不是生成问题：

| 规则 | 逻辑 |
|---|---|
| 强风 / 低能见度 / 降雨 | 山顶、海景类机位扣分 |
| 日落条件好 | 只推朝向朝西的机位 |
| 日出条件好 | 只推朝向朝东的机位 |

天气数据来自 Open-Meteo（免费、支持任意经纬度），每一分都能说出理由。

## 机位库：50 → 92

原本手工精选了 50 个机位（深圳/惠州/广州）。这一夜用高德 POI 把它扩到 **92 个**：拉了 891 条 POI 候选，按规则筛选，新增佛山 13 / 东莞 14 / 珠海 15，全部标注朝向和拍摄要点。

筛选不是无脑凑数——比如佛山搜"海滨"出来的全是楼盘名，直接判定不硬凑海景机位。扩充后冒烟测试全绿。

## 实际效果

- 订阅者每天收到的是"今晚值不值得出门 + 去哪拍"，不是一堆气象数字
- 新增城市零成本：机位入库 + 订阅者上报坐标即可
- 整条链路免费：Open-Meteo 免费额度 + 高德开放平台 + wxpusher
