## 它是谁

给装修老板做的一站式 **AI 获客系统**。客户进来问"89平全包多少钱",它答;问"预算15万能装吗",它聊;留下微信,钉钉直接弹给老板。

卖的不是"AI 客服",是**"替你接住每一个装修客户"**。

## 完整链路

```
客户咨询 → LLM 抽取(面积/户型/预算/时间/联系方式) → 意向分级(高/中/低)
        → SQLite 落库 → 老板面板 + 高意向钉钉推送(24h 去重)
```

## 为什么不是普通聊天机器人

- "89平三房,预算15万,十月装" → 自动识别为**高意向**
- "随便问问" → **低意向**,不打扰老板
- 留了联系方式 → **钉钉实时响**,老板只负责回电话
- 每个会话累积成一张客户卡,面板看到全部流量:"今日咨询 17 / 高意向 4 / 待跟进 8"

## 技术栈

| 层 | 用什么 |
|---|---|
| Web | Flask(客户页 + 老板面板) |
| 大模型 | DeepSeek(问答 + 结构化留资抽取) |
| 存储 | SQLite |
| 通知 | 钉钉群机器人 webhook |

## 为什么做

装修圈有现成人脉(汇鹏/装小蜜),本地老板缺的是"客户来了怎么接住"。先拿一个真实老板做案例,验证"本地服务业 AI 获客"这个方向——做成了再复制到婚庆、汽美、健身这些一样"重复提问 + 没专职客服"的行业。
