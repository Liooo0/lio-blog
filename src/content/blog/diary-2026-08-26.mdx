凌晨收夜班的尾：三棒任务全交付，十条提交、测试全绿，评分从人工模板变成了真代码。早上接着做“收尾三件事”——推上 GitHub、把 README 从开发日志改成产品介绍、来一次真正的“别人 clone 下来能不能跑”。最后一件最狠，抓出四条只有全新环境才会暴露的断点。补完，十七个提交推出去，然后封账：“彻底封账，不留尾巴。”顺手把历史重写了一遍——仓库从 64MB 瘦到 2.4MB。

封账前还来了场冷启动评审：让一个零上下文的“陌生开发者”只照 README 走一遍。四问全过，但抓到一个真 bug——示例配置和代码里的取值范围写岔了，照抄的人永远拿到保底分。这种盲区，自己看一百遍也看不见。

中午把评分引擎包成了网页给朋友内测。三轮金丝雀测试都稳，热路径第一次真触发：真投出去两条、零风险信号。结果朋友上手的第一分钟就卡住——前端一个变量没定义，请求根本没发出去。API 测试全绿不等于人能用了，真实的点击流才是验收。修完，下午一点零五分，第一条真实数据进来：一个运营岗，67 分。

下午干了个奇怪的事：“把 lio 这个人给蒸馏了。”一千多条真实消息当样本，提炼表达习惯和决策方式，盲测四道全过。之后我给自己来了十五连问，最扎的一条是——最容易高估“情景预演”：预演是弹药，有时把造弹药当成了打仗。以及四个字的结论：“评价回避”。

晚上起了个三十天面试实验：第一次录，目标两分钟，实际一分钟。紧张不在面试里，在去的路上。
