这两周没憋出什么大项目，杂事一堆。趁记忆还热，流水账记一笔。

## 让另一个 AI 来给我挑刺

job-hunter 用了几个月，一直有个疑案：一些明显对口的岗位，莫名其妙被"公司背调"环节过滤掉了。

我把整个项目复制了一份只读副本，让一个全新的 Agent 进去办案——不带任何作者滤镜。

它还真翻出来了。`deep_filter.py` 里有一行：

```python
jobs = [...只保留目标公司...] or data
```

精确匹配的结果后面挂了个 `or data`——匹配不到，就拿搜索返回的全量数据兜底。也就是说搜"云链科技"，结果里混进来六条"云链人力资源"的电话销售岗，背调画像直接判成"销售公司"，正常 AI 岗当场枪毙。

Agent 办案的流程很标准：先写复现脚本钉死 bug，再 `git log -L` 考古确认这行是某次提交手滑写错的（不是刻意设计），然后最小改动修掉，两个场景跑绿，全程没碰一行无关代码。

修复目前住在副本里，验完再合回主线。这次最大的收获是个方法论：**让没有历史包袱的第三方读代码，比作者自己盯十遍都灵。**

## 手机连电脑，绕了三个坑

想把手机也接上本机的 Hermes，路上踩了一串：

1. 先查了一圈才发现，**飞书 bot 本来就是外网通道**——websocket 常驻，人在哪都能聊。真正缺的是浏览器开 dashboard 这种场景
2. 起 `hermes serve`，手机访问 404。看提示才知道 serve 是纯后端不带 UI，要用的是 `hermes dashboard --host 0.0.0.0`
3. curl 测登录，cookie 死活不生效。查了半天是 cookie 绑域名——127.0.0.1 登出来的 cookie，对 IP 访问无效。这种坑文档不会写，只能拿头撞

局域网通了之后补外网，选了 Tailscale。brew 装 cask 要 sudo 直接失败；换官网 standalone zip 解压拷进 /Applications。登录链接几分钟就过期，得把 login 进程挂后台再慢慢点链接。最后 `Tailscale ip -4` 吐出 `100.70.53.46`——电脑端入网成功。

手机端还没装 App，暂停中。回头装上登同一个账号，`http://100.70.53.46:9119` 就是口袋里的 Hermes。

## 给 Codex 搬家

顺手把 codex 从 0.146 升到 0.149，然后把 Hermes 这边 **95 个技能全部软链**进 `~/.codex/skills`——加分类前缀防撞名，零复制，删掉链接就还原。

DeepSeek 通道实测跑通，19.7k tokens 一个来回。本地 4090 的通道也配好了（LM Studio 新版 `/v1/responses` 协议），就等那台机器开机验证一次。开机之后，codex 就有零成本档位了。

升级路上的坑照例记下：新版砍了 chat 协议只留 responses、`lmstudio` 成了保留名不能自定义、profile 是独立的 config.toml 文件。

## 短视频定了方向

纠结很久的"要不要做视频"有了结论：做 **AI 搭建/知识分享**类——教别人怎么用 AI 工具搭东西。Dify 知识库、Agent 流水线、装修获客 bot，这些我亲手搭过的项目，每一个都是一期选题。

最大的好处是素材零门槛：不用出门拍一个镜头，屏幕录制 + 配音 + 关键步骤放大标注，就是全部。第一期定了 Dify 知识库，还没开拍，先立此存照。

## 车：继续蹲

FL5 销量追踪更新到 7 月：今年 1-7 月累计上了 329 台牌，预估库存还剩 **570 台上下**，按月销四五十台的节奏，清完要到明年底。

翻译一下：**经销商比我急。** 策略不变——10 月底裸车压到 30 以内就锁，锁不到就等 12 月冲量。库存摆在那，价格只会更松。
